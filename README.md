# Earmark releases

Local-AI audio manager: catalogue, transcribe, search and summarise phone and other recordings on your own GPU.

## Download

**[Earmark 0.1.8 for Windows (x64)](https://raw.githubusercontent.com/blood-ray/earmark-releases/main/Earmark_0.1.8_x64-setup.exe)**

Run the installer (no admin rights needed). Installed copies update themselves from this repository
(latest.json); every update is verified against Earmark's signing key before it is installed.

Released 2026-11-02T03:11:34Z. Faster transcription: several recordings processed side by side, much less file reading for large files on network shares.
