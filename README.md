# Earmark releases

Local-AI audio manager: catalogue, transcribe, search and summarise phone and other recordings on your own GPU.

## Download

**[Earmark 0.1.6 for Windows (x64)](https://raw.githubusercontent.com/blood-ray/earmark-releases/main/Earmark_0.1.6_x64-setup.exe)**

Run the installer (no admin rights needed). Installed copies update themselves from this repository
(latest.json); every update is verified against Earmark's signing key before it is installed.

Released 2026-11-02T01:26:55Z. Much faster on large libraries: GPU memory no longer spills into system RAM, transcription runs before summaries, short clips skip AI summaries.
